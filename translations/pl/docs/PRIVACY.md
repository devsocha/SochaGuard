# Prywatność

**SochaGuard niczego nie zbiera, nie wysyła ani nie udostępnia: wszystko zostaje zaszyfrowane na Twoim urządzeniu, a aplikacja nie korzysta z sieci.**

- Bez konta, analityki, reklam i raportowania awarii.
- Żadne dane nie są przesyłane do autora ani osób trzecich.
- Sejf znajduje się w folderze danych aplikacji w Twoim profilu użytkownika (Windows) lub w prywatnej pamięci aplikacji (Android). Eksporty to pliki, które tworzysz i kontrolujesz.
- Ta strona (GitHub) jest prowadzona przez GitHub i podlega jego polityce prywatności; pobieranie wydań również.

Pytania: otwórz issue (nigdy nie dołączaj sekretów).
