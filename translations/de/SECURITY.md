## Schwachstelle melden

Bitte melde Schwachstellen **vertraulich**:

- Nutze in diesem Repository die GitHub-Funktion **„Report a vulnerability“** (Security → Advisories).

Eröffne bitte keine öffentlichen Issues oder Pull Requests zu Sicherheitsproblemen und füge keine echten Tresore oder Passwörter bei.

Hilfreiche Angaben: betroffene Version, Plattform (Windows / Android), Schritte zur Reproduktion, Auswirkungen.

## Was dich erwartet

- Bestätigung der Meldung innerhalb von **7 Tagen**.
- Eine Korrektur oder ein Abhilfeplan, sobald das Problem bestätigt ist; du wirst auf dem Laufenden gehalten.
- Auf Wunsch Namensnennung in den Release Notes.

## Unterstützte Versionen

SochaGuard ist eine Vorabversion (0.x). Nur das **neueste Release** erhält Sicherheitskorrekturen.

## Geltungsbereich

Im Umfang: Kryptografie und Schlüsselverwaltung, Tresorformat, Entsperr-/Sperrlogik, Verhalten von Autofill und Auto-Type, Datenlecks (Logs, temporäre Dateien, Zwischenablage), Release-Artefakte.

Nicht im Umfang: durch Malware oder Keylogger kompromittierte Geräte, physischer Zugriff auf ein entsperrtes Gerät, schwache Master-Passwörter, Social Engineering.
