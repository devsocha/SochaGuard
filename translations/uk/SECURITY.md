## Як повідомити про вразливість

Повідомляйте про вразливості **приватно**:

- Скористайтеся функцією GitHub **«Report a vulnerability»** (Security → Advisories) у цьому репозиторії.

Не створюйте публічних issue чи pull request щодо проблем безпеки та не додавайте до звіту справжні сховища чи паролі.

Корисні відомості: версія, платформа (Windows / Android), кроки відтворення, наслідки.

## Чого очікувати

- Підтвердження отримання протягом **7 днів**.
- Виправлення або план пом’якшення одразу після підтвердження проблеми; ви будете в курсі.
- Згадка в примітках до випуску, якщо бажаєте.

## Підтримувані версії

SochaGuard — попередня версія (0.x). Виправлення безпеки отримує лише **останній випуск**.

## Межі

У межах: криптографія та робота з ключами, формат сховища, логіка розблокування / блокування, поведінка автозаповнення та auto-type, витоки даних (журнали, тимчасові файли, буфер обміну), артефакти випусків.

Поза межами: пристрій, уже скомпрометований шкідливим ПЗ чи кейлогером, фізичний доступ до розблокованого пристрою, слабкі майстер-паролі, соціальна інженерія.
