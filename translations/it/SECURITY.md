## Segnalare una vulnerabilità

Segnala le vulnerabilità **in privato**:

- Usa la funzione di GitHub **«Report a vulnerability»** (Security → Advisories) in questo repository.

Non aprire issue o pull request pubbliche per problemi di sicurezza e non includere cassaforti o password reali nella segnalazione.

Dettagli utili: versione interessata, piattaforma (Windows / Android), passaggi per riprodurre il problema, impatto.

## Cosa aspettarsi

- Conferma di ricezione entro **7 giorni**.
- Una correzione o un piano di mitigazione appena il problema è confermato; sarai tenuto aggiornato.
- Citazione nelle note di rilascio, se lo desideri.

## Versioni supportate

SochaGuard è una versione preliminare (0.x). Solo l’**ultima release** riceve correzioni di sicurezza.

## Ambito

Nell’ambito: crittografia e gestione delle chiavi, formato della cassaforte, logica di sblocco / blocco, comportamento di compilazione automatica e auto-type, fughe di dati (log, file temporanei, appunti), artefatti delle release.

Fuori ambito: dispositivi già compromessi da malware o keylogger, accesso fisico a un dispositivo sbloccato, password principali deboli, ingegneria sociale.
